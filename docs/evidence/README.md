# AquaLogic Validation Evidence

Evidence files support dated validation checkpoints but do not define current
behavior. Pair them with the commands, scope, and limitations recorded in
[`../DEVELOPMENT_STATUS.md`](../DEVELOPMENT_STATUS.md).

- [`browser-artifacts/`](browser-artifacts/): browser screenshots from responsive
  and feature validation.

When adding evidence, record the scenario and validation date in the relevant
checkpoint before treating the artifact as release evidence.
