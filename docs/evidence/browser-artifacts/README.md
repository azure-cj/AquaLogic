# Browser Validation Artifacts

These screenshots are retained as visual evidence for web validation. They are
not UI specifications; current routes, behavior, and accessibility expectations
remain in the web area guide, API contract, development status, and source/tests.

Current artifact groups include:

- admin fleet, alerts, analytics, thresholds, tank drawer, navigation, and
  actuator command-center views;
- public mobile tank and offline views;
- responsive command-center widths from 390px through 1600px.

The dated validation checkpoint in
[`../../DEVELOPMENT_STATUS.md`](../../DEVELOPMENT_STATUS.md) is the source for
the test context and limitations of these images.
